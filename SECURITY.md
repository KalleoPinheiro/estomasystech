# Política de Segurança

O EstomaSysTech trata dados de saúde (LGPD). Levamos vulnerabilidades a sério.

## Como reportar

Não abra issue pública. Use o relato privado do GitHub:
<https://github.com/KalleoPinheiro/estomasystech/security/advisories/new>

Inclua o que encontrou, os passos para reproduzir e o impacto. Durante os testes, não acesse,
altere nem baixe dados de terceiros.

## Versões suportadas

Apenas a versão em produção (a última tag `v*` na `main`) recebe correções de segurança.
