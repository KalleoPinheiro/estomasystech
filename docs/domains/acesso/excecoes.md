# Acesso — matriz de exceções

> **TL;DR:** para cada caso de exceção do domínio (entrada inválida, sem permissão, outra empresa, duplicidade, concorrência, falha de integração, estado terminal), o teste que o prova. Um teste de estrutura (`tests/bdd/matriz-excecoes.test.ts`) falha se uma categoria some, se uma regra citada não existe ou se um teste citado sumiu. Regras: [README do domínio](README.md); método: [ADR-049](../../adr/049-matriz-de-excecoes-por-dominio.md).
